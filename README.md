## How to Download
1. Download the folder containing all files of the module you want to install.
2. Move the downloaded folder into your `.minecraft/config/ChatTriggers/modules` directory.
3. Run `/ct modules` in game and ensure that the downloaded module is present.
4. Run `/ct refresh` to ensure the module is loaded.
